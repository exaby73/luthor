---
title: Annotations
description: Every luthor annotation, the modifier it adds, the parameter types it applies to, and the rules that apply to all of them.
---

Each annotation adds one modifier to the validator the generator derives from the parameter type. Most have a class form that takes arguments and a lowercase constant for the no-argument case: `@IsEmail()` and `@isEmail` are the same.

## Class-level

| Annotation | Effect |
|---|---|
| `@luthor` | Marks the class as a model. The generator emits the five generated items for it. |

## Parameter-level

| Annotation | Constant | Applies to | Adds |
|---|---|---|---|
| `@HasMin(n)` | | `String` | [`.min(n)`](/reference/string/min), a minimum length |
| `@HasMin(n)` | | `int` | [`.min(n)`](/reference/number/min), a minimum value |
| `@HasMax(n)` | | `String` | [`.max(n)`](/reference/string/max), a maximum length |
| `@HasMax(n)` | | `int` | [`.max(n)`](/reference/number/max), a maximum value |
| `@HasMinDouble(n)` | | `double` | `.min(n)` |
| `@HasMaxDouble(n)` | | `double` | `.max(n)` |
| `@HasMinNumber(n)` | | `num` | `.min(n)` |
| `@HasMaxNumber(n)` | | `num` | `.max(n)` |
| `@HasLength(n)` | | `String` | [`.length(n)`](/reference/string/length) |
| `@Contains(s)` | | `String` | [`.contains(s)`](/reference/string/contains) |
| `@StartsWith(s)` | | `String` | [`.startsWith(s)`](/reference/string/starts-with) |
| `@EndsWith(s)` | | `String` | [`.endsWith(s)`](/reference/string/ends-with) |
| `@MatchRegex(p)` | | `String` | [`.regex(p)`](/reference/string/regex) |
| `@IsEmail()` | `@isEmail` | `String` | [`.email()`](/reference/string/email) |
| `@IsUri(allowedSchemes: [...])` | `@isUri` | `String` | [`.uri()`](/reference/string/uri) |
| `@IsUrl(allowedSchemes: [...])` | `@isUrl` | `String` | [`.url()`](/reference/string/url) |
| `@IsIp(version: ...)` | | `String` | [`.ip()`](/reference/string/ip) |
| `@IsUuid()` | `@isUuid` | `String` | [`.uuid()`](/reference/string/uuid) |
| `@IsCuid()` | `@isCuid` | `String` | [`.cuid()`](/reference/string/cuid) |
| `@IsCuid2()` | `@isCuid2` | `String` | [`.cuid2()`](/reference/string/cuid2) |
| `@IsDateTime()` | `@isDateTime` | `String` | [`.dateTime()`](/reference/string/date-time). Added without annotation for `DateTime` parameters. |
| `@IsEmoji()` | `@isEmoji` | `String` | [`.emoji()`](/reference/string/emoji) |
| `@IsFile()` | `@isFile` | any | Replaces the type's validator with [`l.file()`](/reference/types/file) |
| `@WithCustomValidator(fn)` | | any | [`.custom(fn)`](/reference/modifiers/custom) |
| `@WithSchemaCustomValidator(fn)` | | any | [`.customWithSchema(fn)`](/reference/modifiers/custom-with-schema) |
| `@luthorForwardRef` | | a model type | Wraps the reference in [`forwardRef()`](/reference/forward-ref) |

Every annotation except `@luthor` and `@luthorForwardRef` accepts `message` and `messageFn`, which pass through to the modifier. [Message functions](/concepts/messages) covers them.

## Rules

Put annotations on constructor parameters. The generator reads the first constructor's parameters and nothing else. An annotation on a field declaration, as in `@HasMin(18) final int age;` with `required this.age`, is ignored without a warning.

An annotation that does not match the parameter type is ignored. `@HasMin(2)` on a `double` adds nothing; use `@HasMinDouble(2)`. `@IsEmail()` on an `int` adds nothing.

Functions passed to `@WithCustomValidator`, `@WithSchemaCustomValidator`, and `messageFn` have to be top-level functions or static methods. The generated code refers to them by name.

The order of generated string modifiers is fixed and does not follow annotation order. `@HasMin(2) @HasMax(50)` produces `.max(50).min(2)`. Because every validation runs, the order changes only the order of messages.

## Example

```dart
@luthor
@freezed
abstract class SignUp with _$SignUp {
  const factory SignUp({
    @HasMin(2) @HasMax(50) required String name,
    @IsEmail() required String email,
    @HasMin(8) required String password,
    @WithSchemaCustomValidator(matchesPassword, message: 'Passwords must match')
    required String confirm,
    @HasMin(18) int? age,
    @IsUrl(allowedSchemes: ['https']) String? website,
  }) = _SignUp;

  factory SignUp.fromJson(Map<String, dynamic> json) => _$SignUpFromJson(json);
}
```

```dart title="Generated schema"
Validator $SignUpSchema = l.withName('SignUp').schema({
  SignUpSchemaKeys.name: l.string().max(50).min(2).required(),
  SignUpSchemaKeys.email: l.string().email().required(),
  SignUpSchemaKeys.password: l.string().min(8).required(),
  SignUpSchemaKeys.confirm: l
      .string()
      .customWithSchema(matchesPassword, message: "Passwords must match")
      .required(),
  SignUpSchemaKeys.age: l.int().min(18),
  SignUpSchemaKeys.website: l.string().url(allowedSchemes: ["https"]),
});
```
