title: '.required()'
description: Rejects null and missing values.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

Adds one validation: the value is not `null`. Inside a schema, a missing key counts as `null`, so `.required()` is also what makes a field mandatory. It says nothing about emptiness: `''` and `[]` pass. Returns a plain `Validator`, so call type-specific modifiers before it. [Optional by default](/concepts/optional-by-default) explains the design.

## Signature

```dart wrap
Validator required({String? message, String? Function()? messageFn})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value is required`. `value` is replaced by the field name when there is one.

## Code generation

The generator adds `.required()` to every parameter that is non-nullable, not `dynamic`, and has no `@Default`. Dart's `required` keyword plays no part.

## Example
