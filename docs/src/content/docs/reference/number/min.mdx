---
title: '.min()'
description: Requires a number to be at least a given value.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';
import Verdict from '../../../../components/Verdict.astro';

Passes when the value is at least the limit. The limit has the same type as the validator: `int` on `l.int()`, `double` on `l.double()`, `num` on `l.number()`.

## Signature

```dart wrap
IntValidator min(int minValue, {String? message, String? Function()? messageFn})     // on l.int()
DoubleValidator min(double minValue, {String? message, String? Function()? messageFn}) // on l.double()
NumberValidator min(num minValue, {String? message, String? Function()? messageFn})    // on l.number()
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `minValue` | `int, double, or num` | The minimum accepted value, inclusive. |
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be greater than or equal to 18`, with the limit as given. `value` is replaced by the field name when there is one.

## Code generation

The annotation depends on the parameter type. Put it on the constructor parameter.

| Parameter type | Annotation |
|---|---|
| `int` | `@HasMin(n)` |
| `double` | `@HasMinDouble(n)` |
| `num` | `@HasMinNumber(n)` |

On a `String` parameter, `@HasMin` means a minimum length instead. An annotation that does not match the parameter type is ignored.
