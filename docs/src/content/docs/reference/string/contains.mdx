title: '.contains()'

Passes when `value.contains(string)` is true. The comparison is case-sensitive.

## Signature

```dart wrap
StringValidator contains(String string, {String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `string` | `String` | The substring that has to appear. |
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value does not contain "@"`, with the substring quoted. `value` is replaced by the field name when there is one.

## Code generation

`@Contains(s)`. Put the annotation on the constructor parameter.

## Example
