Passes when the string matches the CUID pattern: a `c` followed by at least eight characters that are not whitespace or `-`.

## Signature

```dart wrap
StringValidator cuid({String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be a valid cuid`. `value` is replaced by the field name when there is one.

## Code generation

`@IsCuid()`, or the constant `@isCuid`. Put the annotation on the constructor parameter.

## Example
