Passes when the string matches Luthor's email pattern: a local part, one `@`, and a domain. It checks shape, not deliverability.

## Signature

```dart wrap
StringValidator email({String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be a valid email address`. `value` is replaced by the field name when there is one.

## Code generation

`@IsEmail()`, or the constant `@isEmail`. Put the annotation on the constructor parameter.
