Passes when the string matches the IPv4 pattern, the IPv6 pattern, or, when `version` is given, only that version. `IpVersion` is an enum with `v4` and `v6`.

## Signature

```dart wrap
StringValidator ip({IpVersion? version, String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `version` | `IpVersion?` | `IpVersion.v4` or `IpVersion.v6`. Omit to accept either. |
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be a valid IP address`, `value must be a valid IPv4 address`, or `value must be a valid IPv6 address`, depending on `version`. `value` is replaced by the field name when there is one.

## Code generation

`@IsIp(version: IpVersion.v4)`. There is no constant shorthand for this annotation. Put the annotation on the constructor parameter.
