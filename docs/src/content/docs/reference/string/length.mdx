title: '.length()'
description: Requires a string of exactly a given number of characters.

import { Tabs, TabItem } from '@astrojs/starlight/components';

Passes when `value.length` equals `length`.

## Signature

```dart wrap
StringValidator length(int length, {String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `length` | `int` | The only accepted length. Must be 0 or more. |
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be exactly 3 characters long`. `value` is replaced by the field name when there is one.

## Code generation

`@HasLength(n)`. Put the annotation on the constructor parameter.

## Example
