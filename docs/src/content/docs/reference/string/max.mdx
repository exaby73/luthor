title: '.max()'
description: Requires a string of at most a given number of characters.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';
import Verdict from '../../../../components/Verdict.astro';

Passes when `value.length` is at most `maxLength`.

## Signature

```dart wrap
StringValidator max(int maxLength, {String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `maxLength` | `int` | The largest accepted length. Must be 0 or more. |
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must not be more than 3 characters long`. `value` is replaced by the field name when there is one.

## Code generation

`@HasMax(n)` on a `String` parameter. On an `int` parameter the same annotation means a maximum value. Put the annotation on the constructor parameter.

## Example
