title: '.url()'
description: Requires the string to be a URL with a scheme and a host.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';
import Verdict from '../../../../components/Verdict.astro';

Passes when the string parses as a URI that has both a scheme and a host, and, if `allowedSchemes` is given, the scheme is in that list. Schemes are compared case-insensitively. `'example.com'` fails because it has no scheme, and `'mailto:dev@example.com'` fails because it has no host.

## Signature

```dart wrap
StringValidator url({List<String>? allowedSchemes, String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `allowedSchemes` | `List<String>?` | Schemes to accept, such as `['https']`. |
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be a valid URL`. With `allowedSchemes`, the message continues with `. Allowed scheme is https` or `. Allowed schemes are http, https`. `value` is replaced by the field name when there is one.

## Code generation

`@IsUrl(allowedSchemes: [...])`, or the constant `@isUrl`. Put the annotation on the constructor parameter.
