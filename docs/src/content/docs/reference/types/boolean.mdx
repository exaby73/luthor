title: 'l.boolean()'
description: Requires a bool.

import Verdict from '../../../../components/Verdict.astro';

Passes when the value is a `bool`. The method is named `boolean` because `bool` is a Dart type name. Strings such as `'true'` fail.

## Signature

```dart wrap
Validator boolean({String? message, String? Function()? messageFn})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be a bool`. `value` is replaced by the field name when there is one.

## Code generation

A `bool` parameter maps to `l.boolean()`.

```dart wrap
required bool acceptedTerms, // l.boolean().required()
```

To require `true` rather than any `bool`, add a [custom validator](/reference/modifiers/custom).

## Example

```dart
final flag = l.boolean();
```

<Verdict
  title="flag.validateValue(input)"
  cases={[

    { input: "false", pass: true },
    { input: "'true'", pass: false, message: "value must be a bool" },
  ]}
/>
