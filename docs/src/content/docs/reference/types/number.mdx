---
title: 'l.number()'
description: Requires a num, int or double, and unlocks the number modifiers.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

Passes when the value is a `num`, which covers both `int` and `double`. Returns a validator with [`.min()`](/reference/number/min) and [`.max()`](/reference/number/max) taking `num` limits. Use it for JSON numbers whose representation you do not control.

## Signature

```dart wrap
NumberValidator number({String? message, String? Function()? messageFn})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be a number`. `value` is replaced by the field name when there is one.

## Code generation

A `num` parameter maps to `l.number()`. `@HasMinNumber(n)` and `@HasMaxNumber(n)` add `.min(n)` and `.max(n)`.
