Each annotation adds one modifier to the validator the generator derives from the field type. Most have a class form that takes arguments and a lowercase constant for the no-argument case: `@IsEmail()` and `@isEmail` are the same.

## Class-level

| Annotation | Effect |
|---|---|
| `@luthor` | Marks the class as a model. The generator emits the five generated items for it. |

## Field-level

| Annotation | Constant | Applies to | Adds |
|---|---|---|---|
| `@HasMin(n)` | | `String` | [`.min(n)`](/reference/string/min), a minimum length; `n` must be integral |
| `@HasMin(n)` | | `int`, `double`, `num` | [`.min(n)`](/reference/number/min), a minimum value; integral for `int` |
| `@HasMax(n)` | | `String` | [`.max(n)`](/reference/string/max), a maximum length |
| `@HasMax(n)` | | `int`, `double`, `num` | [`.max(n)`](/reference/number/max), a maximum value |
| `@HasLength(n)` | | `String` | [`.length(n)`](/reference/string/length) |
| `@Contains(s)` | | `String` | [`.contains(s)`](/reference/string/contains) |
| `@StartsWith(s)` | | `String` | [`.startsWith(s)`](/reference/string/starts-with) |
| `@EndsWith(s)` | | `String` | [`.endsWith(s)`](/reference/string/ends-with) |
| `@MatchRegex(p, caseSensitive:, multiLine:, unicode:, dotAll:)` | | `String` | [`.regex(RegExp(p, ...))`](/reference/string/regex) |
| `@IsEmail()` | `@isEmail` | `String` | [`.email()`](/reference/string/email) |
| `@IsUri(allowedSchemes:)` | `@isUri` | `String` | [`.uri()`](/reference/string/uri) |
| `@IsUrl(allowedSchemes:)` | `@isUrl` | `String` | [`.url()`](/reference/string/url) |
| `@IsIp(version:)` | `@isIp` | `String` | [`.ip()`](/reference/string/ip) |
| `@IsUuid()` | `@isUuid` | `String` | [`.uuid()`](/reference/string/uuid) |
| `@IsCuid()` | `@isCuid` | `String` | [`.cuid()`](/reference/string/cuid) |
| `@IsCuid2()` | `@isCuid2` | `String` | [`.cuid2()`](/reference/string/cuid2) |
| `@IsDateTime()` | `@isDateTime` | `String` | [`.dateTime()`](/reference/string/date-time); `DateTime` fields get it without annotation |
| `@IsEmoji()` | `@isEmoji` | `String` | [`.emoji()`](/reference/string/emoji) |
| `@IsFile(accept:)` | `@isFile` | any, including package classes such as `MultipartFile` | Replaces the type's validator with [`l.file()`](/reference/types/file); on a `List<X>` field, `accept` receives the whole list |
| `@WithCustomValidator(fn)` | | any except `Null` | [`.custom(fn)`](/reference/modifiers/custom) |
| `@WithSchemaCustomValidator(fn)` | | any except `Null` | [`.customWithSchema(fn)`](/reference/modifiers/custom-with-schema) |
| `@luthorForwardRef` | | a model type | Deprecated. It has no effect, because every nested reference is already a [forward reference](/reference/forward-ref). Remove it. |

Every annotation except `@luthor` and `@luthorForwardRef` accepts `message` and `messageBuilder`, which pass through to the modifier. A `messageBuilder` has to be a top-level function or a static method. [Message builders](/concepts/messages) covers both.

## Rules

Annotations may sit on the constructor parameter or on the field, including fields reached through `super.` parameters. Before 1.0 only parameters were read.

An annotation on a field type it does not apply to fails generation with an error naming the field. `@HasMin(2)` on a `bool`, `@IsEmail` on an `int`, and `@HasLength` on a `List` are errors, not silently ignored. A fractional `@HasMin` or `@HasMax` on an `int` or `String` field is also an error.

Functions passed to `@WithCustomValidator`, `@WithSchemaCustomValidator` and `messageBuilder` have to be top-level functions or static methods, and take the field's type: `bool isEven(int value)`, `bool matchesPassword(String value, SchemaData data)`.

Modifiers are generated in the order the annotations are written. `@HasMin(2) @HasMax(50)` generates `.min(2).max(50)`.

## Example

```dart
bool matchesPassword(String value, SchemaData data) =>
    value == data['password'];

enum AccountType { personal, business }

@luthor
@freezed
abstract class SignUp with _$SignUp {
  const factory SignUp({
    @HasMin(2) @HasMax(50) required String name,
    @IsEmail() required String email,
    @HasMin(8) required String password,
    @WithSchemaCustomValidator(matchesPassword, message: 'Passwords must match')
    required String confirm,
    @HasMin(18) int? age,
    @IsUrl(allowedSchemes: ['https']) String? website,
    @Default(AccountType.personal) AccountType accountType,
  }) = _SignUp;

  factory SignUp.fromJson(Map<String, dynamic> json) => _$SignUpFromJson(json);
}
```
