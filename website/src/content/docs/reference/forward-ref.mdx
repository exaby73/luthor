`forwardRef()` wraps a function that returns a validator. Luthor calls the function each time a value is validated, so the validator it returns can be one that is still being defined when the schema literal is built. [Schemas](/concepts/schemas) has the explanation.

## Signature

```dart
ValidatorReference<O> forwardRef<O>(Validator<O> Function() resolver)

abstract interface class ValidatorReference<O> {
  Validator<O> resolve();
}
```

`ValidatorReference` is the interface shared by every validator and every forward reference. Schema fields, list elements, map keys and values, and union options are all typed as `ValidatorReference`, so a forward reference fits wherever a validator does.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `resolver` | `Validator<O> Function()` | Called on each validation. Return the validator to use, with modifiers such as `.required()` applied inside the function. |

## Example

```dart
late final SchemaValidator node;
node = l.schema({
  'value': l.string().required(),
  'children': l.list(forwardRef(() => node.required())),
});
```

Two schemas that refer to each other follow the same pattern:

```dart
late final SchemaValidator author;
late final SchemaValidator post;
author = l.schema({
  'name': l.string().required(),
  'posts': l.list(forwardRef(() => post.required())),
});
post = l.schema({
  'title': l.string().required(),
  'author': forwardRef(() => author),
});
```

Recursion is bounded by the input and by [`l.maxDepth`](/concepts/max-depth).

## Code generation

The generator wraps every reference to another model's schema in `forwardRef()`, so self-referential and mutually recursive models work without any annotation.

`@luthorForwardRef` and its class `LuthorForwardRef` are deprecated. The generator still accepts the annotation, and the generated code is the same with or without it. Remove it; the analyzer reports a deprecation warning while it is there. Hand-written `forwardRef()` in runtime code is unaffected and still needed for a hand-written schema that refers to itself.

```dart
List<Node>? children, // l.list(forwardRef(() => $NodeSchema.required()))
Node? parent,         // forwardRef(() => $NodeSchema)
```
