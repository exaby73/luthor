Returns a copy of the validator whose default messages start with `name` instead of `value`. It matters only when the validator validates a value directly; inside a schema, the field key is the field name and `withName` is ignored.

## Signature

```dart wrap
Self withName(String? name)
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `name` | `String?` | The field name, or `null` to clear it. |

## Issue

Code `none`. Default message: `withName` adds no validation. It changes the `fieldName` of every issue the validator produces, and so the `value` prefix of default messages.

## Code generation

Every generated schema ends in `.withName('ModelName')`, which names the whole model in the `must be a map` message when `$ModelValidate` receives something that is not a map.
