Passes when `value.isFinite` is true. `NaN`, `double.infinity` and `double.negativeInfinity` are doubles, so they pass `l.double()` and `l.num()` unless `.finite()` is present. `jsonDecode` never produces them, but values computed in Dart can.

## Signature

```dart wrap
NumberValidator<N, O> finite({String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `notFinite`. Default message: `value must be a finite number`. `value` is replaced by the field name when there is one.

## Code generation

No annotation adds `.finite()` yet. Apply it to the generated schema's field by hand if you need it, or check it in a `@WithCustomValidator`.
