Passes when the value is at most `maxValue`. The limit has the validator's number type.

## Signature

```dart wrap
NumberValidator<N, O> max(N maxValue, {String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `maxValue` | `N` | The largest accepted value, inclusive. `params['max']`. |
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `tooBig`. Default message: `value must be less than or equal to 100`. `value` is replaced by the field name when there is one.

## Code generation

`@HasMax(n)` on an `int`, `double` or `num` field, with the same rules as `@HasMin`.
