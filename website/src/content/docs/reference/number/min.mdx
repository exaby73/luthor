Passes when the value is at least `minValue`. The limit has the validator's number type: `int` on `l.int()`, `double` on `l.double()`, `num` on `l.num()`.

## Signature

```dart wrap
NumberValidator<N, O> min(N minValue, {String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `minValue` | `N` | The smallest accepted value, inclusive. `params['min']`. |
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `tooSmall`. Default message: `value must be greater than or equal to 18`, with the limit as given. `value` is replaced by the field name when there is one.

## Code generation

`@HasMin(n)` on an `int`, `double` or `num` field. `n` is a `num`; a fractional value on an `int` field fails generation. On a `String` field the same annotation is a minimum length.
