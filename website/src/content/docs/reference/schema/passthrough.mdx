Returns a copy of the schema that copies keys it does not declare into the output, without validating them. Non-string keys are converted with `toString()`. The default is to strip unknown keys. Only `SchemaValidator` has this method.

## Signature

```dart wrap
SchemaValidator<O> passthrough()
```

## Issue

Code `none`. Default message: Adds no validation.

## Code generation

The generator emits `.passthrough()` when it cannot name every key the serializer may read: a field with `@JsonKey(readValue:)`, a private field with `@JsonKey(includeFromJson: true)`, or a `@MappableClass(hook:)`.
