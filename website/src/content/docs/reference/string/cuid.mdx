Passes when the whole string is a `c` followed by at least eight characters that are not whitespace or `-`, case-insensitively. This is a format check only.

## Signature

```dart wrap
StringValidator<O> cuid({String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidCuid`. Default message: `value must be a valid cuid`. `value` is replaced by the field name when there is one.

## Code generation

`@IsCuid()`, or the constant `@isCuid`. Put the annotation on the constructor parameter or the field.
