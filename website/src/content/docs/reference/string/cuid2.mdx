Passes when the string is a lowercase letter followed by lowercase letters and digits. That is the whole CUID2 grammar, so any lowercase word passes. Add [`.length()`](/reference/string/length) if you generate CUID2s of a fixed length.

## Signature

```dart wrap
StringValidator<O> cuid2({String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidCuid2`. Default message: `value must be a valid cuid2`. `value` is replaced by the field name when there is one.

## Code generation

`@IsCuid2()`, or the constant `@isCuid2`. Put the annotation on the constructor parameter or the field.
