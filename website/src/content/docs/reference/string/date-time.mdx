Passes when `DateTime.tryParse(value)` returns a value. That accepts ISO 8601 dates and date-times, with or without a time zone.

## Signature

```dart wrap
StringValidator dateTime({String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be a valid date`. `value` is replaced by the field name when there is one.

## Code generation

`@IsDateTime()`, or the constant `@isDateTime`. A parameter of type `DateTime` gets `.dateTime()` without any annotation, because JSON carries dates as strings. Put the annotation on the constructor parameter.
