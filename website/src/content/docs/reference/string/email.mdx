Passes when the string follows the RFC 5322 address syntax. It accepts single-label domains such as `user@localhost`, does not limit the local part to 64 characters, and rejects internationalized (Unicode) addresses. It checks shape, not deliverability.

## Signature

```dart wrap
StringValidator<O> email({String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidEmail`. Default message: `value must be a valid email address`. `value` is replaced by the field name when there is one.

## Code generation

`@IsEmail()`, or the constant `@isEmail`. Put the annotation on the constructor parameter or the field.
