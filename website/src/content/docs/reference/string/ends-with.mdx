Passes when `value.endsWith(suffix)` is true. Case-sensitive.

## Signature

```dart wrap
StringValidator<O> endsWith(String suffix, {String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `suffix` | `String` | The required suffix. `params['suffix']`. |
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `missingSuffix`. Default message: `value does not end with ".dart"`. `value` is replaced by the field name when there is one.

## Code generation

`@EndsWith(s)`. Put the annotation on the constructor parameter or the field.
