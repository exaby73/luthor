Passes when `value.length` equals `length`. Throws `ArgumentError` for a negative length.

## Signature

```dart wrap
StringValidator<O> length(int length, {String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `length` | `int` | The only accepted length. `params['length']`. |
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidLength`. Default message: `value must be exactly 3 characters long`. `value` is replaced by the field name when there is one.

## Code generation

`@HasLength(n)`. Put the annotation on the constructor parameter or the field.
