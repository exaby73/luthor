Passes when `value.length` is at least `minLength`. Throws `ArgumentError` when the validator is built with a negative length.

## Signature

```dart wrap
StringValidator<O> min(int minLength, {String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `minLength` | `int` | The smallest accepted length. `params['min']`. |
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `tooShort`. Default message: `value must be at least 8 characters long`; `1 character long` for a limit of 1. `value` is replaced by the field name when there is one.

## Code generation

`@HasMin(n)` on a `String` field. On a number field the same annotation means a minimum value. Put the annotation on the constructor parameter or the field.
