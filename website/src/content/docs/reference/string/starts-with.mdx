Passes when `value.startsWith(prefix)` is true. Case-sensitive.

## Signature

```dart wrap
StringValidator<O> startsWith(String prefix, {String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `prefix` | `String` | The required prefix. `params['prefix']`. |
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `missingPrefix`. Default message: `value does not start with "+"`. `value` is replaced by the field name when there is one.

## Code generation

`@StartsWith(s)`. Put the annotation on the constructor parameter or the field.
