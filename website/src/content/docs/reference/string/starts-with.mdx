title: '.startsWith()'
description: Requires the string to start with a given prefix.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

Passes when `value.startsWith(string)` is true. The comparison is case-sensitive.

## Signature

```dart wrap
StringValidator startsWith(String string, {String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `string` | `String` | The required prefix. |
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value does not start with "+"`, with the prefix quoted. `value` is replaced by the field name when there is one.

## Code generation

`@StartsWith(s)`. Put the annotation on the constructor parameter.
