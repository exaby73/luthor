title: '.uri()'
description: Requires the string to parse as a URI, optionally with one of a set of schemes.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';
import Verdict from '../../../../components/Verdict.astro';

Passes when `Uri.tryParse(value)` returns a value and, if `allowedSchemes` is given, the scheme is in that list. `Uri.tryParse` is lenient and accepts most strings, including `'not a uri at all'`. When you expect a web address, use [`.url()`](/reference/string/url), which also requires a host.

## Signature

```dart wrap
StringValidator uri({List<String>? allowedSchemes, String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `allowedSchemes` | `List<String>?` | Schemes to accept, such as `['https']`. Compared exactly, so list lowercase schemes. |
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be a valid uri`. With `allowedSchemes`, the message continues with `. Allowed scheme is https` or `. Allowed schemes are http, https`. `value` is replaced by the field name when there is one.

## Code generation

`@IsUri(allowedSchemes: [...])`, or the constant `@isUri` with no scheme restriction. Put the annotation on the constructor parameter.
