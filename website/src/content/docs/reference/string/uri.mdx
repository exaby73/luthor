Passes when the string parses as a URI with a scheme and contains no whitespace. `mailto:dev@example.com` passes; `example.com` and `not a uri at all` fail. With `allowedSchemes`, the scheme has to be in the list, compared case-insensitively. For a web address with a host, use [`.url()`](/reference/string/url).

## Signature

```dart wrap
StringValidator<O> uri({List<String>? allowedSchemes, String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `allowedSchemes` | `List<String>?` | Schemes to accept, such as `['https']`. `params['allowedSchemes']`. |
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidUri`. Default message: `value must be a valid uri`, continued with `. Allowed scheme is https` or `. Allowed schemes are http, https` when schemes are given. `value` is replaced by the field name when there is one.

## Code generation

`@IsUri(allowedSchemes: [...])`, or the constant `@isUri`. A `Uri` field maps to `l.string()` without `.uri()`; add the annotation if you want the check. Put the annotation on the constructor parameter or the field.
