Passes when the string has the eight-four-four-four-twelve hexadecimal shape of a UUID.

## Signature

```dart wrap
StringValidator uuid({String? message, String? Function()? messageFn})
```

Available on `l.string()`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be a valid uuid`. `value` is replaced by the field name when there is one.

## Code generation

`@IsUuid()`, or the constant `@isUuid`. Put the annotation on the constructor parameter.

## Example
