Passes when the string has the 8-4-4-4-12 hexadecimal shape of a UUID. Any version and variant digit is accepted.

## Signature

```dart wrap
StringValidator<O> uuid({String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidUuid`. Default message: `value must be a valid uuid`. `value` is replaced by the field name when there is one.

## Code generation

`@IsUuid()`, or the constant `@isUuid`. Put the annotation on the constructor parameter or the field.
