title: 'l.any()'

import { Tabs, TabItem } from '@astrojs/starlight/components';
import Verdict from '../../../../components/Verdict.astro';

Always passes. Use it for a field you want listed in a schema without constraints. `.required()` still works on it, and so do custom validators.

## Signature

```dart wrap
Validator any()
```

## Error message

None. `l.any().required()` reports `value is required` for `null`.

## Code generation

A `dynamic` parameter maps to `l.any()`. It never gets `.required()`, because `dynamic` admits `null`.
