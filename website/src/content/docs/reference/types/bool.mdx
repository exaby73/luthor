Passes when the value is a `bool`. Returns a `BoolValidator<bool?>`. Strings such as `'true'` fail. To require `true` rather than any `bool`, add a [custom validator](/reference/modifiers/custom).

## Signature

```dart wrap
BoolValidator<bool?> bool({String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidType`. Default message: `value must be a bool`. `value` is replaced by the field name when there is one.

## Code generation

A `bool` parameter maps to `l.bool()`.
