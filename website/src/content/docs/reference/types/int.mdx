Passes when the value `is int`. Returns an `IntValidator`, a `NumberValidator<int, int?>` with [`.min()`](/reference/number/min), [`.max()`](/reference/number/max) and [`.finite()`](/reference/number/finite). On the VM, `42.0` is a `double` and fails. On the web every number is a JavaScript number, so `42.0 is int` is true there. For JSON that may carry either form, use [`l.num()`](/reference/types/num).

## Signature

```dart wrap
NumberValidator<int, int?> int({String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidType`. Default message: `value must be an integer`. `value` is replaced by the field name when there is one.

## Code generation

An `int` parameter maps to `l.int()`. `@HasMin(n)` and `@HasMax(n)` add `.min(n)` and `.max(n)`; a fractional `n` on an `int` field fails generation.
