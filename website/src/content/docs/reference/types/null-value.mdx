Passes only when the value is `null`. Useful for a field that must be absent or cleared.

## Signature

```dart wrap
Validator nullValue({String? message, String? Function()? messageFn})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageFn` | `String? Function()?` | Called on failure to produce the message. `message` wins when both are given. |

## Error message

`value must be null`. `value` is replaced by the field name when there is one.

## Code generation

A parameter of type `Null` maps to `l.nullValue()`. `json_serializable` and `freezed` cannot serialize a `Null`-typed field, so use this with `dart_mappable` or a hand-written `fromJson`.
