Passes when the value `is num`, which covers `int` and `double`. Returns a `NumValidator` with [`.min()`](/reference/number/min), [`.max()`](/reference/number/max) and [`.finite()`](/reference/number/finite) taking `num` limits. Use it for JSON numbers whose representation you do not control.

## Signature

```dart wrap
NumberValidator<num, num?> num({String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidType`. Default message: `value must be a number`. `value` is replaced by the field name when there is one.

## Code generation

A `num` parameter maps to `l.num()`. `@HasMin(n)` and `@HasMax(n)` add `.min(n)` and `.max(n)`, and `n` may be fractional.
