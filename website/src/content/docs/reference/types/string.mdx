Passes when the value is a `String`. Returns a `StringValidator<String?>`, which has every [string modifier](/reference/string/min); `.required()` narrows the output to `String`. `null` passes until you add `.required()`.

## Signature

```dart wrap
StringValidator<String?> string({String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidType`. Default message: `value must be a string`, with `params['expected']` set to `'string'`. `value` is replaced by the field name when there is one.

## Code generation

A `String` parameter maps to `l.string()`; `DateTime` and `Uri` parameters map to `l.string()` with `.dateTime()` for `DateTime`. Non-nullable parameters without a default get `.required()`.

## Example

<Verdict id="type.string" />

Lengths in `.min()`, `.max()` and `.length()` count UTF-16 code units, like `String.length`.
