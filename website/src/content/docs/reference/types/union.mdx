Tries each option in order against the same value and returns the output of the first that passes. When none passes, it reports one `invalidUnion` issue whose `params['issues']` holds every option's issues. Returns a `UnionValidator<Object?>`; the output type is `Object?` because the options may differ. Use it for list elements of mixed shape, `l.list(l.union([...]))`, or for a field that may be an id or an email.

## Signature

```dart wrap
UnionValidator<Object?> union(List<ValidatorReference<Object?>> options, {String? message, MessageBuilder? messageBuilder})
```

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `options` | `List<ValidatorReference<Object?>>` | Tried in order. Must not be empty; an empty list throws `ArgumentError` when the validator is built. |
| `message` | `String?` | Replaces the default error message. |
| `messageBuilder` | `MessageBuilder?` | Builds the message from the issue. `message` wins when both are given. See [Message builders](/concepts/messages). |

## Issue

Code `invalidUnion`. Default message: `value does not match any allowed option`. `value` is replaced by the field name when there is one.

## Code generation

The generator does not emit unions yet. `freezed` union classes fail generation with an error that names the class.
