In this tutorial you turn the `User` model from [Your first schema](/start/first-schema) into an annotated class, generate its schema, and validate input with the generated function. It uses `freezed` and `json_serializable`. [Models without freezed](/generator/models) shows the other setups. The generated code on this page is the real output of `luthor_generator` for the model shown.

<Steps>

1. Add the packages.

   ```sh
   dart pub add luthor freezed_annotation json_annotation
   dart pub add dev:build_runner dev:luthor_generator dev:freezed dev:json_serializable
   ```

   On Dart 3.11 use `freezed` 3.2.x. `freezed` 4 needs Dart 3.13 or later.

2. Write the model.

   Annotate the class with `@luthor` next to `@freezed`. Put Luthor's annotations on the constructor parameters: `@IsEmail()` adds `.email()`, `@HasMin(18)` on an `int` adds `.min(18)`. Non-nullable parameters without a default become required fields; nullable ones stay optional.

   ```dart title="lib/user.dart"
   import 'package:freezed_annotation/freezed_annotation.dart';
   import 'package:luthor/luthor.dart';

   part 'user.freezed.dart';
   part 'user.g.dart';

   @luthor
   @freezed
   abstract class User with _$User {
     const factory User({
       @HasMin(2) required String name,
       @IsEmail() required String email,
       @HasMin(18) int? age,
     }) = _User;

     factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
   }
   ```

3. Run the generator.

   ```sh
   dart run build_runner build
   ```

   `user.g.dart` now holds five generated items for `User`: the schema `$UserSchema`, the validate function `$UserValidate`, the `validateSelf` extension, the schema keys `UserSchemaKeys`, and the error keys `UserErrorKeys`. The schema is the one you would have written by hand:

   <Generated file="tutorial_user.g.dart" from="final SchemaValidator $UserSchema" to="$UserSchema.validateSchema(json, fromJson: User.fromJson);" title="lib/user.g.dart (excerpt)" />

4. Validate with the generated function.

   `$UserValidate` accepts any input, validates it, and on success converts it with `User.fromJson`. You get a `ValidationResult<User>`.

   ```dart title="bin/main.dart"
   import 'package:luthor/luthor.dart';
   import 'package:my_app/user.dart';

   void main() {
     final result = $UserValidate({
       'name': 'Ada',
       'email': 'ada@example.com',
       'age': 36,
     });

     switch (result) {
       case ValidationSuccess(:final data):
         print('+ ${data.name} <${data.email}>');
       case ValidationFailure(:final errors):
         print('- $errors');
     }
   }
   ```

   <Output id="gen.tutorial.switch" title="dart run bin/main.dart, valid then invalid input" />

   <Verdict id="gen.tutorial" />

5. Read errors with the error keys.

   `UserErrorKeys` is a record whose fields hold the error path of each model field. Use it with `getError` instead of a string, and a renamed field becomes a compile error instead of a `null`.

   ```dart
   print(result.getError(UserErrorKeys.email));
   print(result.getError(UserErrorKeys.age));
   ```

   <Output id="gen.tutorial.errorKeys" />

6. Validate an existing instance.

   The generated extension validates a model you already have, by serialising it with `toJson()` and running the schema.

   ```dart
   final user = User(name: 'A', email: 'ada', age: 12);
   print(user.validateSelf().isValid);
   print(user.validateSelf().errors);
   ```

   <Output id="gen.tutorial.validateSelf" />

</Steps>
