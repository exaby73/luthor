In this tutorial you build a validator for an email address, run it against three inputs, and branch on the result. You need a Dart project with `luthor` installed. [Installation](/installation) covers that.

<Steps>

1. Create `bin/main.dart` and start from `l`.

   Every validator starts from `l`, the validator factory. Calling a type method such as `string()` returns a validator that checks the Dart type. Each modifier you chain after it returns a new validator with one more validation.

   ```dart title="bin/main.dart"
   import 'package:luthor/luthor.dart';

   void main() {
     final email = l.string().email().required();
   }
   ```

   `l.string()` checks that the value is a `String`. `.email()` checks that it is an email address. `.required()` rejects `null`, and it also changes the type: `email` is a `StringValidator<String>`, so a successful result holds a `String`, not a `String?`.

2. Validate a value.

   Call `validate`. It accepts any input, returns a `ValidationResult<String>`, and never throws. `isValid` tells you which case you got.

   ```dart title="bin/main.dart" ins={6-8}
   import 'package:luthor/luthor.dart';

   void main() {
     final email = l.string().email().required();

     print(email.validate('dev@example.com').isValid);
     print(email.validate('bad').isValid);
     print(email.validate(null).isValid);
   }
   ```

   Run it with `dart run bin/main.dart`. You should see:

   <Output id="email.isValid" title="dart run bin/main.dart" />

3. Read the result.

   `ValidationResult` is sealed with two cases, `ValidationSuccess` and `ValidationFailure`. Replace the three prints with a `switch`. The compiler requires both cases, and the success case gives you the typed value.

   ```dart title="bin/main.dart" ins={6-13}
   import 'package:luthor/luthor.dart';

   void main() {
     final email = l.string().email().required();

     for (final input in ['dev@example.com', 'bad', null]) {
       switch (email.validate(input)) {
         case ValidationSuccess(:final data):
           print('+ $data');
         case ValidationFailure(:final messages):
           print('- $input: ${messages.first}');
       }
     }
   }
   ```

   <Output id="email.switch" title="dart run bin/main.dart" />

   The same run as a report:

   <Verdict id="email" />

4. Name the value.

   Messages say `value` because the validator has no name. Give it one with `withName`, and the name replaces `value` in every message the chain produces.

   ```dart title="bin/main.dart" del={4} ins={5}
   import 'package:luthor/luthor.dart';

   void main() {
     final email = l.string().email().required();
     final email = l.string().email().required().withName('email');
   ```

   <Verdict id="email.named" />

5. Reuse the base validator.

   Validators are immutable. Chaining returns a new validator and leaves the one you chained from unchanged, so a base validator can branch into several without one leaking into another.

   ```dart
   final text = l.string();
   final email = text.email();
   final uuid = text.uuid();

   print(text.validate('anything').isValid);
   print(email.validate('anything').isValid);
   print(uuid.validate('anything').isValid);
   ```

   <Output id="reuse" />

</Steps>
